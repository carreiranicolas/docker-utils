# docker-utils

Anotações e guia prático de Docker, feitos ao longo de um curso.

## Conteúdo

O guia completo está em [comandos-docker.md](comandos-docker.md) e cobre:

- Containers (`run`, `ps`, `stop`, `start`, `logs`, `rm`, `exec`...)
- Dockerfile e build de imagens
- Docker Hub (`login`, `push`, `pull`)
- Volumes (anônimos, nomeados e bind mounts)
- Networks (bridge, host, macvlan, none)
- Docker Compose
- Limpeza do ambiente (`prune`)

No final do guia tem um resumão com os comandos principais pra consulta rápida.
